# MPS（主生产计划）案例与MPS文档说明


## 1. 案例背景与数学模型

本案例基于主生产计划（MPS）系统的核心功能，构建了一个**能力受限的批量生产计划问题（Capacitated Lot-Sizing Problem, CLSP）**模型。为了将其转化为具体的数值实例并生成可被求解器（如HiGHs）处理的MPS文档，我们设计了一个消费品生产场景。

在这个场景中，企业需要为一种产品制定未来两个周期（$t=1, 2$）的生产计划。根据需求预测和订单汇总，第 1 期的总需求量 $D_1 = 10$，第 2 期的总需求量 $D_2 = 15$。在成本方面，每次开机生产的准备成本 $S = 50$，单位产品的库存持有成本 $H = 2$，单位产品的直接生产成本 $C = 10$。在产能和库存限制方面，每期的最大可用产能 $Cap = 20$，期初库存量 $I_0 = 5$，并且要求每期期末必须保持至少 $SS = 2$ 的安全库存。此外，生产单位产品消耗的产能时间 $p = 1$，且假设产能计算中不包含额外的准备时间消耗。

### 1.1 决策变量

为了构建优化模型，我们定义了三组决策变量。

第一组是连续变量 $X_1$ 和 $X_2$，它们分别代表第 1 期和第 2 期的实际生产数量。第二组是二进制变量 $Y_1$ 和 $Y_2$，用于指示第 1 期和第 2 期是否开机进行生产。如果 $X_t > 0$，则 $Y_t$ 必须为 1，从而触发固定的生产准备成本。第三组是连续变量 $I_1$ 和 $I_2$，它们分别表示第 1 期和第 2 期末的计划可用库存量（PAB）。

### 1.2 目标函数

主生产计划优化的核心目标是最小化总成本，这其中包括了直接生产成本、固定的生产准备成本以及库存持有成本。因此，模型的目标函数被设定为：
$$ \text{Minimize} \quad 10 X_1 + 10 X_2 + 50 Y_1 + 50 Y_2 + 2 I_1 + 2 I_2 $$

### 1.3 约束条件

模型包含了四类约束条件，以确保生产计划在物流守恒、逻辑关联和产能限制上是合理的。

**库存平衡约束（Inventory Balance Constraints）**
这是最核心的物流守恒定律。第 1 期的期末库存等于期初库存加上本期生产量减去本期需求量，即 $I_1 = I_0 + X_1 - D_1$，代入具体数值转化为 $I_1 - X_1 = -5$。同理，第 2 期的期末库存约束为 $I_2 = I_1 + X_2 - D_2$，转化为标准形式为 $I_2 - I_1 - X_2 = -15$。

**生产与准备逻辑约束（Setup Logic Constraints）**
这组约束用于建立连续变量 $X$ 和二进制变量 $Y$ 之间的逻辑关联。我们采用 Big-M 方法（取 $M=100$）。对于第 1 期，约束为 $X_1 \le 100 \cdot Y_1$，即 $X_1 - 100 \cdot Y_1 \le 0$。对于第 2 期，约束为 $X_2 \le 100 \cdot Y_2$，即 $X_2 - 100 \cdot Y_2 \le 0$。

**产能约束（Capacity Constraints）**
这组约束确保了每期的生产任务不会超过系统的最大可用能力。根据设定，第 1 期的约束为 $X_1 \le 20$，第 2 期的约束为 $X_2 \le 20$。

**安全库存约束（Safety Stock Constraints）**
为了应对需求波动，系统要求每个周期末的库存水平不低于设定的安全水位。因此，第 1 期的约束为 $I_1 \ge 2$，第 2 期的约束为 $I_2 \ge 2$。

## 2. MPS文档结构说明

根据上述数学模型，我们生成了标准的 MPS 文件（`mps_example.mps`），其结构严格遵循线性规划的输入规范。

| 区域名称 | 功能描述 | 案例具体应用 |
| :--- | :--- | :--- |
| **NAME** | 定义模型名称 | 命名为 `MPS_Example` |
| **OBJSENSE** | 定义优化方向 | 设定为 `MIN`（最小化） |
| **ROWS** | 定义目标函数和约束条件名称及类型 | `E` 代表等式约束，`L` 代表 $\le$ 约束，`G` 代表 $\ge$ 约束 |
| **COLUMNS** | 定义变量在目标函数和约束条件中的系数 | 使用 `'MARKER'` 标签明确区分了二进制变量 $Y_1$ 和 $Y_2$ |
| **RHS** | 定义约束条件右侧的常数项 | 填入了 -5, -15, 20, 2 等具体边界数值 |
| **BOUNDS** | 定义变量的取值范围和类型 | 使用 `BV` 类型声明 $Y_1$ 和 $Y_2$ 为二进制变量 |

## 3. HiGHs求解结果分析

使用 HiGHs 求解器对生成的 MPS 文档进行求解后，我们得到了成本最小化的最优主生产计划方案。

求解器找到的最优目标函数值（即总成本）为 $Z = 328$。在生产决策上，求解器选择在两个周期都开机生产（$Y_1 = 1, Y_2 = 1$）。具体而言，第 1 期的生产数量为 $X_1 = 7$，第 2 期的生产数量为 $X_2 = 15$。

这一生产决策直接决定了库存状态。在第 1 期末，库存量 $I_1 = 2$，其计算逻辑为期初的 5 加上生产的 7 再减去需求的 10，刚好满足了安全库存的要求。在第 2 期末，库存量 $I_2 = 2$，其计算逻辑为上期结转的 2 加上生产的 15 再减去需求的 15，同样刚好满足安全库存要求。

该主生产计划方案在满足所有需求、产能限制和安全库存要求的前提下，找到了平衡生产成本、准备成本和库存成本的最优解。尽管每次开机都会产生较高的准备成本，但由于需求量较大且库存持有成本不容忽视，系统最终选择在两期都进行生产，从而有效避免了过多的库存积压和资金占用。


| 变量    | 含义          | 最优值       |
| ----- | ----------- | --------- |
| `OBJ` | 最小总成本（目标函数） | **328.0** |
| `Y1`  | 第1期是否生产     | 1（生产）     |
| `Y2`  | 第2期是否生产     | 1（生产）     |
| `X1`  | 第1期生产数量     | 7         |
| `X2`  | 第2期生产数量     | 15        |
| `I1`  | 第1期末库存      | 2         |
| `I2`  | 第2期末库存      | 2         |
